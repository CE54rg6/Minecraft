# Minecraft 2D

A simple 2D version of Minecraft built with HTML, CSS, and JavaScript.

## Description
This project is a basic 2D Minecraft-style game where the player can:
- Select tools (Axe, Pickaxe, Shovel)
- Break tiles according to the selected tool
- Collect broken tiles in the inventory
- Place tiles back into the world from the inventory
- Reset the world to its original state

## How to Play
1. Open `landing.html` to see the instructions.
2. Click **Start Game** to enter the world.
3. Select a tool from the toolbar.
4. Click on matching tiles to break them.
5. Click on an item in the inventory, then click on an empty tile to place it.
6. Use the Reset button to restore the world.

## Tools
- **Axe** → Removes Tree (wood + leaves)
- **Pickaxe** → Removes Rock
- **Shovel** → Removes Dirt and Grass

## Files
- `landing.html` → Landing page with instructions
- `index.html` → Main game page
- `style.css` → All styles
- `script.js` → Game logic
