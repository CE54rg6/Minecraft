MINECRAFT 2D

HTML • CSS • JavaScript

A simple 2D version of Minecraft.

How to Play

  1. Select a tool from the toolbar (Axe, Pickaxe or Shovel).
  2. Click on a tile in the world that matches the tool.
  3. The tile will be removed and added to your inventory.
  4. Click on an item in the inventory to select it, then click on an empty tile to place it.
  5. Use the Reset button to restore the world to its original state.

Tools

  • Axe → Removes Tree (wood + leaves)
  • Pickaxe → Removes Rock
  • Shovel → Removes Dirt and Grass
